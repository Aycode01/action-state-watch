# Contributing

We welcome contributions to `action-state-watch`!

To maintain codebase consistency and security, all contributions must follow the guidelines detailed in the primary repository contribution guide.

Please refer to the main repository [`CONTRIBUTING.md`](../CONTRIBUTING.md) for:
- Development workflow and pull request guidelines
- Coding style conventions and linting rules (`npm run lint`, `npm run typecheck`)
- Test suite requirements (`npm test`)
- Security and trust boundary constraints
